# Many Hands
#### purpose: little game designed to help learn java 2d development  
#### Author: Alex R
#### Disclaimer: Copilot Artificial intelligence was used in the creation of this code for troubleshooting and generalize design directions. The objective of this code is to practice java 2d development not for commercial distribution. All ideas, assets, and code was created by the author. 

## Structure
    - Logic: Package used to control and coordinate all other objects
    - UI: Package containing display frame, key handlers, and support for user interaction
    - Grid: Package supporting main mapping and navigation objects as well as generation  
    - Resources: Directory containing graphics and other information
